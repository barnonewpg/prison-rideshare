# Prison Rideshare [![UI](https://github.com/barnonewpg/prison-rideshare/actions/workflows/ui.yml/badge.svg)](https://github.com/barnonewpg/prison-rideshare/actions/workflows/ui.yml) [![API](https://github.com/barnonewpg/prison-rideshare/actions/workflows/api.yml/badge.svg)](https://github.com/barnonewpg/prison-rideshare/actions/workflows/api.yml)

A database to track rides, reïmbursements and miscellania for [Bar None’s prison rideshare project](https://barnonewpg.org/rideshare/).

- [`api/`](api): the Phoenix API
- [`ui/`](ui): the Ember front-end

These were previously separate repositories, [prison-rideshare-api](https://github.com/backspace/prison-rideshare-api) and [prison-rideshare-ui](https://github.com/backspace/prison-rideshare-ui); their full histories are preserved here.
